# Historical documentation

These records describe earlier revisions and working sessions. Their test totals,
open issues, instructions and Jira states are historical, not the current release
checklist. Use the [documentation guide](../README.md) for maintained sources.

- [Testing snapshots](testing/README.md) retain previous execution and audit evidence.
- `HANDOFF_SPRINT1.md` and `HANDOFF_SPRINT2.md` retain sprint handoffs.
- `HANDOFF_SESSION.md` retains an earlier session record; its restart instructions
  are not current setup instructions or permission to perform an action.

Archiving preserves evidence; it does not close findings. Current unresolved items
belong in [release closeout](../testing/release-closeout.md) and the requirement
manifest. Preserve authentic assessment deliverables even if they are old.
